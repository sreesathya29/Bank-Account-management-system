What is this project?
🏧

ATM Simulator

A full desktop ATM simulator — you get a card number, PIN, and real transactions like deposit, withdraw, and balance check. It mimics exactly how a real ATM works.

☕

Built in Java

Uses Java Swing for the UI — that means real clickable windows and buttons, not a terminal. The backend is MySQL for storing your transactions safely.

🔒

PIN-Based Security

Login requires a card number + PIN. You can even change your PIN inside the app. Every transaction is tied to your unique PIN so data stays separated.

📊

Mini Statement

View your last transactions with dates and amounts — exactly like an ATM receipt. The card number is masked (e.g., 1234XXXXXXXX5678) for privacy.

Testing (QA Breakdown)
🔬
Unit Testing — Testing individual functions
⌄
Each function like deposit(), withdraw(), checkBalance() is tested individually to make sure it does exactly what it's supposed to do. Think of it like testing each ingredient before cooking the dish.
🔗
Integration Testing — Modules talking to each other
⌄
Tests what happens when the login module passes the PIN to the transaction module. Like checking if a relay baton handoff actually works — not just the individual runners.
🖥️
System Testing — The full end-to-end experience
⌄
The whole system is run as a real user would use it — from sign up, through transactions, to logout. This is the final boss level of testing to confirm everything works together.
